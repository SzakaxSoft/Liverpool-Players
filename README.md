# Liverpool-Players

Football Player Stats GUI

• This is a simple Java Swing project that displays a football-themed graphical user interface.

• Features:
  • Displays a main menu with three buttons:
    • Player Stats
    • Transfer Rumours
    • News
  • When clicking "Player Stats":
    • Opens a new window
    • Shows sample player data using buttons
    • Each row includes:
      • Name
      • Age
      • Nationality
  • Players shown as examples:
    • Alisson, 32, Brazil
    • Frimpong, 24, Netherlands

• Technologies Used:
  • Java
  • Swing (built-in Java GUI toolkit)

• How to Run:
  • Make sure Java is installed (JDK 8 or newer)
  • Save the code to a file called Main.java
  • Open a terminal or command prompt
  • Compile the code:
    javac Main.java
  • Run the program:
    java Main
